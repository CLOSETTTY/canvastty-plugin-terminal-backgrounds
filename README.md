# Fine Dots Backgrounds Pack for CanvasTTY

A curated collection of **35 animated Fine-Dots (Braille 2×4 matrix) backgrounds** for CanvasTTY terminals. 

Features clean geometric, cyber, retro, space, and aesthetic loops with full runtime animation and live previews.

- **Retro & Pixel**: Aesthetic Drive, Outrun Grid, Synthwave Grid, Synth Sunset, Pixel Runner, Pixel Loop, Voxel Golem, DVD Bounce, Pixel Horizon
- **Memes & Cute**: Dancing Cats, Komaru Cat, Cat Stare, Banana Komaru, Eshkere Cats, Okak Cat, Dancing Bear, Skeleton Dance, Very Interesting, Oguzki Bezdari
- **Anime Aesthetic**: Girl in Rain, Anime Action, Discipline Routine

---

## 🚀 Installation in CanvasTTY

1. Open **CanvasTTY**.
2. Go to **Settings** (`⚙`) → **Plugins** (Плагины).
3. Search for `backgrounds` or `fine-dots`.
4. Click **Install**.
5. Open the plugin from the Canvas menu to preview and apply any background directly to your terminals!
