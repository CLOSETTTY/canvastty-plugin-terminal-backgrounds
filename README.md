# ✨ Fine Dots Backgrounds Pack for CanvasTTY

<p align="center">
  <strong>Curated collection of 35 animated Braille 2×4 subpixel matrix backgrounds for CanvasTTY terminals.</strong><br>
  🎮 35 Live Scenes · ⚡ Subpixel Matrix · 🪟 Windows · 🐧 Linux · 🍎 macOS<br>
  <a href="#-gallery--live-previews">View Gallery</a> ·
  <a href="#-installation">Installation</a> ·
  <a href="LICENSE">MIT License</a>
</p>

A high-performance animated backgrounds collection designed specifically for [CanvasTTY](https://github.com/howdeploy/CanvasTTY). All scenes are rendered in **Fine Dots** (Braille 2×4 matrix, ) providing smooth subpixel geometry and zero distortion without stretching or cropping.
